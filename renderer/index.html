技能
    安装 SKILL 到其他 Agent

    链接 = 在目标目录创建指向唯一副本的目录联接（junction），不复制文件，源更新所有 Agent 即时生效。要求同一磁盘（NTFS）。

    设置
    主题
    强调色
    点选即预览，点「保存设置」后写入配置；主题会随 WebDAV 备份同步到其他机器。
    弹窗遮罩
    调整弹窗背后空白的模糊与变暗程度，拖动即时预览。
    WebDAV 云同步
    云端根目录固定为 cc-skill-sync，每台机器在它下面各占一个子目录；多台机器共用一个网盘也不会互相覆盖。
    备份内容 = 全局 + 项目内所有实体 SKILL（链接不会上传）；密码保存在本机配置文件中，请注意磁盘安全。
    机器与配置
    机器标识决定云端哪个子目录是本机的。重装系统后会生成新标识，在恢复弹窗里勾一下「这就是这台电脑」即可认领回来，之后备份仍写回原来那个目录；机器名只用于显示，随备份上传。
    配置管理
    把 Agents、项目、WebDAV 配置导出为 JSON 文件随身携带；或通过 WebDAV 在多台设备间同步配置。
    恢复默认只影响 Agents、SKILL 目录与项目列表，不会删除磁盘上的任何文件。
    网络代理
    支持 http:// 与 socks5://，可写成 http://用户:密码@主机:端口。WebDAV 同步与 SKILL 市场都走这里；代理配置只存本机，不进云备份。
    GitHub Token（可选）
    大多数场景用不上它：匿名额度（每小时 60 次）对偶尔装几个 SKILL 完全够用。检索频繁撞上限流、或想提高 GitHub 检索精度时再考虑；填了额度提升到 5000 次。Token 只会发给 github.com，绝不发给 skills.sh 等第三方站点。
    从 GitHub 安装
    支持三种链接：仓库地址（整仓扫描 SKILL）、/tree/ 子目录（精确定位到某个 SKILL）、zip 直链。
    合并重复 SKILL · 一份实体 + N 个链接

    同一 SKILL 在多个目录各有一份实体副本时，可只保留一份，其余移入回收站并替换为「链接」——之后只需维护保留的那份，所有 Agent 即时生效。多份内容不同时请先确认保留哪份。

    ⚠从云端恢复
    来源机器 上传设备 上传时间 远程路径 备份大小 包含内容 备份来源
    要重建哪些 Agent 的全局 SKILL
    恢复将覆盖本机同名的全局 SKILL
    云端机器档案

    云端按机器分目录：每台备份过的机器一个子目录，备份包与它那一份信息都在里面。可以直接用别的机器的备份来恢复本机 —— 那只会还原全局 SKILL，项目级的只在恢复本机自己的备份时才回来。
