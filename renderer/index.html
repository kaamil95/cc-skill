总览

技能
    安装 SKILL 到其他 Agent

    链接 = 在目标目录创建指向唯一副本的目录联接（junction），不复制文件，源更新所有 Agent 即时生效。要求同一磁盘（NTFS）。

    新建 SKILL
    导入 SKILL
    设置 · Agents 与 SKILL 目录

    每个 Agent 可关联多个 SKILL 目录；同一目录关联多个 Agent 时即为共享 SKILL 库。改动后点击「保存设置」生效。

    项目
    WebDAV 云同步
    备份内容 = 全局 + 项目内所有实体 SKILL（链接不会上传）；密码保存在本机配置文件中，请注意磁盘安全。
    配置管理
    把 Agents、项目、WebDAV 配置导出为 JSON 文件随身携带；或通过 WebDAV 在多台设备间同步配置。
    合并重复 SKILL · 一份实体 + N 个链接

    同一 SKILL 在多个目录各有一份实体副本时，可只保留一份，其余移入回收站并替换为「链接」——之后只需维护保留的那份，所有 Agent 即时生效。多份内容不同时请先确认保留哪份。

    操作日志
    扫描 / 安装 / 合并 / 删除的结果都会记录在这里，程序异常也会被捕获；错误提示可直接点击查看。
